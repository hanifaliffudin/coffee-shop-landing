# Emberline Coffee

A responsive coffee-shop landing page built with React, TypeScript, and Vite. Emberline is a fictional concept brand created for this project.

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

The locally bundled coffee photography in `public/images` is sourced from Unsplash and credited in the page footer. The page does not use a backend, submit forms, or connect to an ordering service.
